# L02 — Stochastic market clearing

This folder contains two-stage stochastic market-clearing examples with uncertain wind production.

- `Stochastic Market Clearing.py` — stochastic market clearing with day-ahead decisions and scenario-dependent redispatch.
- `Stochastic with reserve requirement.py` — adds an explicit system reserve requirement to the stochastic formulation.

Both examples are designed to be studied together with the corresponding lecture material.
