# L03 — Stochastic Benders decomposition

These examples apply Benders decomposition to stochastic power-market optimisation.

Recommended files for students:

- `Stochastic Benders Decomposition_Final.py` — main two-generator teaching example.
- `Stochastic Benders 10 Gen.py` — expanded ten-generator example.

The `_archive-BK` directory contains earlier/backup development variants and is retained only for reference.
