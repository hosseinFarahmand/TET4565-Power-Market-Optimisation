# L02 — Energy and reserve optimisation

`Energy_reserve.py` illustrates co-optimisation of energy dispatch and reserve capacity. It includes energy production costs, reserve-capacity offer costs, generation limits, system demand, a reserve requirement, and rationing as a high-cost feasibility option.

Run from the repository root:

```bash
python "code-examples/L02-Energy-Reserve-Optimisation/Energy_reserve.py"
```
