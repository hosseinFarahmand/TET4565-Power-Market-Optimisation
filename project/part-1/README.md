# PMO Interim Submission – Project Part 1

This folder is intended for material related to the first part of the TET4565 project.

## Main tasks

1. **Problem formulation and data**
   - Motivate a relevant power-market optimisation problem.
   - Formulate it as a two-stage stochastic optimisation problem.
   - Identify the uncertain parameters and the information available at each stage.
   - Process, clean, visualise, and describe the relevant data.

2. **Model implementation and comparison**
   - Implement the optimisation model.
   - Compare relevant modelling approaches and solutions.

3. **Decomposition**
   - Develop and test a decomposition-based implementation where required by the project description.

## Working principle

Prefer a **well-defined and manageable problem** that allows good analysis and understanding over an unnecessarily large model.

Use the official Canvas project description as the authoritative source for assessment requirements, submission details, and updates.
