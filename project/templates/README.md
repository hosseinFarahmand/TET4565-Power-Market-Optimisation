# Suggested Project Folder Template

Each group can use a structure similar to:

```text
project-group-XX/
├── README.md
├── data/
│   ├── raw/
│   └── processed/
├── src/
│   ├── model.py
│   ├── data_processing.py
│   └── analysis.py
├── notebooks/
├── results/
├── figures/
└── report/
```

Do not commit confidential, restricted, or very large raw datasets unless this is explicitly permitted.
