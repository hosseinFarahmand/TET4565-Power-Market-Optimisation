# Contributing to the TET4565 Repository

## Suggested workflow

1. Pull the latest version of the repository.
2. Create a descriptive branch for substantial changes.
3. Make focused changes.
4. Commit with a clear message.
5. Push the branch.
6. Open a pull request when review is useful.
7. Merge after review and delete the branch when finished.

## Commit message examples

- `add tutorial 1 starter code`
- `fix indexing in stochastic model example`
- `update project part 1 guidance`
- `add data-processing example`

## Course material

Only upload material that is appropriate to share with the class and for which you have permission to publish.
